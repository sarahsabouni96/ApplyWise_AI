An AI-powered job application assistant that evaluates job opportunities against a candidate's profile and generates tailored cover letters for suitable positions.

ApplyWise AI helps candidates make more informed job application decisions. By analyzing job descriptions alongside a candidate's skills, qualifications, and experience, it assesses job suitability and generates personalized cover letters when a position is a good match.

Features

Job Description Analysis: Extracts key information, including job title, company, location, employment type, remote-work options, required qualifications, and skills.

Candidate–Job Matching: Compares job requirements with the candidate's profile and calculates a match score from 0 to 100.

Strengths and Skill Gaps: Identifies relevant experience, matching qualifications, missing requirements, and potential concerns.

Application Recommendation: Provides a recommendation based on the candidate–job match.

Location and Commuting Assessment: Evaluates remote-work suitability and commuting considerations based on the candidate's location and the job location.

AI-Generated Cover Letters: Generates a tailored cover letter for suitable positions using the candidate's profile and the job description.

Downloadable Results: Allows users to download the generated cover letter.

How It Works

The application follows a structured workflow:

Provide a job description: Paste the text of a job advertisement into the application.

Analyze the position: The AI extracts the main job details, responsibilities, and requirements.

Evaluate the match: The extracted requirements are compared with the candidate's profile.

Review the assessment: The application presents a match score, strengths, skill gaps, concerns, and a recommendation.

Assess location suitability: Remote-work arrangements and commuting considerations are evaluated.

Generate a cover letter: If the position is considered a suitable match, the AI generates a tailored cover letter.

Download the result: Save the cover letter for review and further editing.

Technology Stack

Python — Application logic and workflow

Streamlit — Interactive web interface

Google Gemini API — Job analysis, candidate–job matching, and cover letter generation

JSON — Structured AI outputs and candidate profile data
